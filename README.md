# cassetteutil

`cassetteutil` is command line tool for macOS that converts between binary
data and audio cassette records of various computers. If you have a machine
with a `TAPE IN` jack and a dream, you've come to the right place.

### Supported formats ###

* Apple II (monitor)

`cassetteutil` supports only output Apple II monitor encoding at the moment.
Grand plans for the future, though.

### Usage ###
* plug your Mac's headphone jack into your computer's cassette port
* run `cassetteutil --input-file homework.dat`
* hit `LOAD`

Check `cassetteutil help` for more options.
